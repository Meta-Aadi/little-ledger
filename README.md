# Little Ledger

A simple full-stack expense tracker.

## Features

- Add expenses
- View expenses
- Edit expenses
- Delete expenses
- Total spending
- Category-wise spending
- Highest expense
- Persistent SQLite storage

## Technologies

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Python
- FastAPI

Database:
- SQLite

## How to run

Install dependencies:

pip install fastapi uvicorn

Start backend:

python -m uvicorn backend.main:app --reload

Then open index.html.
